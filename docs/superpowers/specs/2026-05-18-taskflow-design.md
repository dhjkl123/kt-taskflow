## 아키텍처

단일 `index.html` 파일에 HTML 구조, CSS 스타일, JS 로직을 모두 포함한다.  
별도 서버 없이 브라우저에서 직접 열어서 사용 가능하다.

### 데이터 모델

```js
{
  id: Number,       // Date.now() 기반 고유 ID
  title: String,    // 업무 제목
  status: String    // "todo" | "inProgress" | "done"
}
```

## 기능 명세

### 업무 추가
- 입력창에 제목 입력 후 "추가" 버튼 클릭 또는 Enter 키
- 공백/빈 문자열 입력 시 추가 안 됨 (alert 없이 무시)
- 추가 후 입력창 자동 초기화
- 새 업무의 기본 상태: `todo` (할 일)

### 업무 삭제
- 각 업무 항목의 삭제 버튼 클릭 시 즉시 제거
- 확인 다이얼로그 없이 바로 삭제

### 상태 변경
- 각 업무 항목에 드롭다운 선택기 제공
- 선택지: 할 일 / 진행 중 / 완료
- 선택 즉시 상태 반영, UI 업데이트

### 필터 탭
- 전체 / 할 일 / 진행 중 / 완료 탭
- 탭 클릭 시 해당 상태의 업무만 표시
- 각 탭에 현재 개수 표시

---

## UI 스타일

- 배경: 흰색, 심플/미니멀
- 카드형 리스트 (각 업무가 둥근 모서리 카드)
- 상태별 색상 구분:
  - 할 일: 회색
  - 진행 중: 파란색
  - 완료: 초록색 + 텍스트 취소선
- 반응형 (모바일 고려, 최대 너비 600px 중앙 정렬)
